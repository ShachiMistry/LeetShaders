the problem & solution
Why is shader grading hard?
"Same GLSL, different pixels on different machines. And a user can just sample the reference image to fool a pixel diff."
  • GPU driver variance across Chrome, ANGLE, and Mesa
  • Adversarial submissions: hardcoded texture lookups pass pixel diff
  • No existing graded platform, Shadertoy is a playground
Solution: two-stage hybrid judge
Stage 1  MAE ~5ms  fast pixel comparison  +  Stage 2  Claude Opus 4.7 ~8s  borderline only

01 · Judge & Rendering · src/judge/
WebGL2 pipeline & MAE scoring
  • Singleton shared context, one canvas across the whole app
  • 512×512 RGBA8 offscreen framebuffer, guaranteed color-renderable
  • Full-screen triangle trick, 3 vertices, zero buffer allocation
  • Context-loss recovery via webglcontextrestored
  • 2 000ms watchdog kills runaway shaders
score = max(0, 100 − (mae / tolerance) × 100)
5-tap GPU Gaussian pre-pass absorbs cross-driver variance.
Sharp patterns (checkerboard) use no blur.
// VERT_SRC — pipeline.ts:7-14
#version 300 es
out vec2 v_uv;
void main() {
  // full-screen triangle, no VBO needed
  float x = float(gl_VertexID & 1) * 4.0 - 1.0;
  float y = float((gl_VertexID >> 1) & 1) * 4.0 - 1.0;
  v_uv = vec2(x, y) * 0.5 + 0.5;
  gl_Position = vec4(x, y, 0.0, 1.0);
}

Key risks

You are a fair, diagnostic judge for a
GLSL shader learning platform.

1. Score visual similarity 0-100. Be tolerant
   of minor numeric or anti-alias drift caused
   by GPU variance.
2. Inspect the user's shader source for
   cheating, e.g. sampling a hardcoded texture
   of the reference, returning a pre-baked
   color array, or otherwise not actually
   computing the image. If detected: flagged=true.
3. Provide a short diagnostic reasoning
   sentence the UI can show. The user is
   learning, feedback should be helpful,
   not punitive.

Return ONLY valid JSON:
{ "visualMatchScore": number 0-100,
  "flagged": boolean,
  "passReasoning": string, ... }
  • Model: claude-opus-4-7
  • JSON enforced via tool_use, no free-text parsing
  • Prompt caching on challenge desc + reference image
