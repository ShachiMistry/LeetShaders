# Challenge: Neon Blossom

## Intended Solution
The user should convert to polar coordinates and use a periodic function of the angle (like `cos(a * 3.0)`) to define a boundary radius.

```glsl
vec2 uv = (gl_FragCoord.xy * 2.0 - u_resolution.xy) / min(u_resolution.y, u_resolution.x);
float r = length(uv);
float a = atan(uv.y, uv.x);
float f = abs(cos(a * 3.0));
float mask = step(r, f * 0.8);
fragColor = vec4(mask * vec3(1.0, 0.0, 1.0), 1.0);
```

## Calibration Notes
- **Tolerance:** `12.0`. Polar patterns are sensitive to coordinate transformations. 
- **Blur:** Enabled (`useBlur: true`). Helps with the sharp edges generated by `step` in a non-Cartesian space.
- **MAE Expectations:**
    - Correct 6-petal flower: 0.0-4.0 MAE.
    - 4-petal or 8-petal: High MAE, fails.
    - Correct shape but wrong color: High MAE, fails.
